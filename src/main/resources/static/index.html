Como funciona a indexação?

  • Extração de Texto: O Apache Tika processa os dados do arquivo PDF.
  • Divisão em Chunks: O texto é dividido em partes semânticas (Token Text Splitter).
  • Geração de Embeddings: Cada trecho é convertido em vetor de 768 dimensões com Ollama (nomic-embed-text).
  • Indexação PostgreSQL: Os vetores são salvos no PGVector para consultas semânticas instantâneas.
